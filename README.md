Clone the repository.
```bash
git clone https://github.com/queue-model-enegep/arrival_counter_enegep_2026.git
```

Set is as the as the currently working directory.
```bash
cd arrival_counter_enegep_2026
```

## Ubuntu / Debian / MacOS

Create a virtual environment.
```bash
python3 -m venv .venv
```

Activate it.
```bash
source .venv/bin/activate
```

Install the dependencies.
```bash
pip3 install -r requirements.txt
```

Run the app locally.
```bash
streamlit run app_counter.py
```

## Windows

Create a virtual environment.
```bash
python -m venv .venv
```

Activate it.
```bash
.venv\Scripts\activate
```

Install the dependencies.
```bash
pip install -r requirements.txt
```

Run the app locally.
```bash
streamlit run app_counter.py
```
